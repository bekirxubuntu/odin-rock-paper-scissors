# Rock Paper Scissors

A console-based implementation of the classic Rock Paper Scissors game, developed using vanilla JavaScript as part of The Odin Project curriculum.

## Description

This project runs entirely in the browser console. The user plays a 5-round match against a randomized computer opponent. Scores are tracked across rounds, and an overall winner is declared at the end of the game.

## Features

- Dynamic 5-round game loop with automatic score tracking.
- Case-insensitive input handling for user choices (e.g., "rock", "ROCK", "RocK").
- Random choice generation for the computer opponent.
- Proper function scope and encapsulation using local variables within the main game function.
- Final game winner declaration based on total scores.

## Technologies Used

- JavaScript (ES6+)
- HTML5
- Git / GitHub

## How to Run

1. Clone or download this repository to your local machine.
2. Open `index.html` in any web browser.
3. Open the Developer Tools console:
   - Windows/Linux: `F12` or `Ctrl + Shift + I`
   - macOS: `Cmd + Option + I`
4. Respond to the browser prompts for each round and view the game output in the console.
